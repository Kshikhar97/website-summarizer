# AI Website Summarizer

An AI-powered Website Summarizer built using Streamlit, BeautifulSoup, and OpenAI-compatible LLM APIs.

## Features

- Extracts content from websites
- Removes irrelevant HTML elements
- Scrapes product and service pages
- Uses AI to generate concise summaries
- Simple Streamlit user interface

## Technologies Used

- Python
- Streamlit
- BeautifulSoup4
- Requests
- OpenAI SDK
- Python-dotenv

## Installation

```bash
pip install -r requirements.txt
```

## Run Locally

```bash
streamlit run main.py
```
